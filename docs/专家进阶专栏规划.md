## 1. 模块一：大模型性能之基 —— 硬件架构、底层算子与自动化设计

> 原始草案使用“系列 + 文章编号”的形式（例如 1.1.1、1.2.1…）。这里保留其结构，并补充“建议的落地优先级”。

### 系列一：现代 AI 计算硬件架构深度剖析

#### 1.1 计算核心的演进：CPU → GPU → NPU/ASIC

- CPU 架构基础：冯·诺依曼、流水线、超标量、乱序
- GPU 架构入门：SIMT、SM、CUDA Cores、Tensor Cores
- \[图解\] NVIDIA GPU 微架构演进（Fermi → Hopper/Blackwell）
- NPU/TPU/ASIC：专用芯片设计哲学
- \[案例\] Google TPU v1–v5
- \[案例\] 华为昇腾 CANN 与达芬奇 AI Core
- \[案例\] 其他 AI 芯片（Gaudi、Trainium/Inferentia…）
- 异构计算：多处理器协作挑战与机会

#### 1.2 存储层次与带宽瓶颈：内存墙

- 存储层次图解：寄存器→缓存→内存→磁盘
- Cache 原理与一致性（MESI）、伪共享
- DRAM：DDRx/LPDDR 及性能瓶颈
- GPU 显存：GDDR vs HBM（带宽/容量/功耗）
- Unified Memory、Zero-Copy、虚拟内存（TLB/页表）
- \[分析\] 内存墙对大模型训练/推理的制约与应对

#### 1.3 高速互联：AI 集群的“神经网络”

- PCIe Gen3–Gen6：拓扑/带宽/在大模型中的作用
- NVLink/NVSwitch：GPU 间互联
- InfiniBand / RoCE：RDMA 与低延迟通信
- CXL：潜力与落地路径
- \[案例\] DGX/HGX 与集群拓扑（Fat-Tree/Dragonfly）

#### 1.4 性能分析与瓶颈定位（强烈建议优先落地）

- `nvidia-smi` 监控
- Nsight Systems：系统级性能剖析
- Nsight Compute：kernel 级深度分析
- Roofline：构建与解读
- \[方法论\] 系统性定位训练/推理瓶颈

### 系列二：极致计算：SIMD 与 GEMM 优化核心

- SIMD：SSE/AVX/AVX-512/AMX、NEON、intrinsics 技巧
- GPU SIMT：warp/wavefront
- GEMM：从朴素三层循环到 tiling/packing/register blocking
- BLAS 与高性能库：OpenBLAS/MKL/BLIS/Eigen、cuBLAS/cublasLt
- 多数据类型与 Tensor Core：FP16/BF16/TF32/INT8/FP8
- Cutlass：高性能 kernel 构建模板库

### 系列三：面向硬件的自动化模型设计（AutoML / NAS）

- NAS 三要素：空间/策略/评估
- DARTS/进化/RL/one-shot 等
- HW-NAS：预测器、多目标优化（Pareto）
- 工具：NNI/Optuna/Ray Tune

## 2. 建议的“专家进阶”落地切片（避免无限扩张）

如果这个仓库要承载多专栏并持续增长，建议“专家进阶”专栏先切一个可交付的第一期：

- **一期（8–12 篇）**：只做“性能分析与方法论 + Roofline + Benchmark 工程化”
