# B-04 L2（Persisting / Access Policy / hitRatio）— 参考结果

> 口径：裸跑 CUDA event **median**；加速比 = `mixed_median / mode_median`。  
> 主对照：`persist` / `thrash` 相对同一 `mixed` 核。`streaming` / `hot` 核不同，只看形状。  
> **禁止**把 `ncu` 附着时程序自打印的 ms 当结论。

## 平台

- GPU：**NVIDIA GeForce RTX 5090**，`sm_120`
- L2=**96.0 MB**，persistingMax=**60.0 MB**，policyWindowMax=128.0 MB
- 默认：`data-mb=64`，`iters=2048`，`set-aside-mb=8`，`window-mb=32`，`hit-ratio=0.25`，`hot-ratio=0.25`，`runs=7`，`warmup=2`，`seed=12345`
- 可执行文件：`02_memory_optim_04_l2_residency`
- 主命令：`--mode modes`

32 MB window / 64 MB 数据都小于 96 MB L2。`window > set-aside`（32>8）但 `window ≪ 总 L2`。

## Modes 全表（主结论 = 最近一次裸跑）

CSV：[`B-04_modes.csv`](B-04_modes.csv)

| mode | first_ms | median_ms | p95_ms | vs mixed |
|---|---:|---:|---:|---:|
| `streaming` | 15.2567 | 15.4141 | 15.4585 | **19.580×** |
| `hot` | 302.9007 | 302.9319 | 302.9789 | **0.996×** |
| `mixed` | 302.0616 | 301.8013 | 302.0148 | **1.000×** |
| `persist` | 302.3329 | 302.2137 | 302.5018 | **0.999×** |
| `thrash` | 301.5612 | 301.6224 | 301.8975 | **1.001×** |

`probe_out0=1047.047`。五档 first ≈ median ≈ p95（计时已套住 kernel stream）。

## 怎么读（本机形状）

1. **hint 不动墙钟。** `persist` **0.999×**、`thrash` **1.001×**，与 `mixed` 贴齐。同核只差 policy，差在抖动带内。  
2. **不是「set-aside 太小所以 thrash」。** 32 MB 窗口装进 96 MB L2；set-aside 只有 8 MB，其余 L2 仍按默认策略留数据。`hitRatio=1` 挤的是 persisting 切片，挤不爆整片 L2。  
3. **`streaming` 19.58× 是合并，不是 residency。** 连续扫 64 MB（已能住进 L2）对随机 gather。`hot` 与 `mixed` 贴齐（0.996×）：两边都在窗口里打点，窗口已在 L2。不要把 19× 写成 persist 红利。  
4. **要看 hint 生效，工作集得先大于 L2**，不是只大于 set-aside。本夹具默认不改；P1 才把 `window` 推过 96 MB。  
5. 出口：本机默认工作集已在 L2 → 停本章。合并 / bank / spill → B-01 / B-02 / B-03。要藏 GMEM→SMEM 延迟 → B-07。跨空间 → B-05。

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DCMAKE_CUDA_ARCHITECTURES=120
cmake --build build --parallel --target 02_memory_optim_04_l2_residency
./build/bin/02_memory_optim_04_l2_residency --mode modes

```

## 作废跑（计时未套住 kernel）

第一次 `--mode modes`：event 记在 default stream，kernel 在 `cudaStreamNonBlocking` 上，median ~4μs。已修。不进主表 / plot。
