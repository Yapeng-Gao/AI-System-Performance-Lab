**路线**：**Microbench-first**——`streaming` / `hot` / `mixed` / `persist` / `thrash`；主对照是同一 mixed 核的 policy off vs on。

**标题**：`B-04. L2：Persisting、Access Policy 与 hitRatio`

**TL;DR 目标**

1. L2 是全片共享缓存；默认 LRU 类，热点不一定留得住。
2. 先划 set-aside，再对 stream 设 Access Policy Window；persisting = 更倾向留，不是 pin。
3. `window > set-aside` 时必须管 `hitRatio`；`hitRatio=1` 容易 thrash。
4. 只在有可复用热点时值得试；纯 streaming / 已 compute-bound 常 ~1×。
5. 跑完必须 reset；主看 `persist` 相对 `mixed` 的 median。

**MVP**

| 配置 | 裁决 |
|---|---|
| `streaming` policy off | 必做（无热点对照） |
| `hot` policy off | 必做（有复用、无 policy） |
| `mixed` policy off | 必做（与 persist 同核） |
| `persist` set-aside + window + hitRatio | 必做 |
| `thrash` 同窗 `hitRatio=1` | 必做 |
| NCU DRAM / L2 hit | 可选 |
| TMA / UM / bank | **不做** |
