## 1. 模块一：大模型性能优化的基石——硬件架构与底层算子

### 第 1 章：现代计算硬件概览与 AI 加速器原理

- CPU/GPU/NPU/TPU/昇腾等架构对比与选型
- GPU 架构深度：SM / Tensor Core / 内存层级 / NVLink
- NPU/类 NPU：片上内存、数据流、指令集与编译
- 内存墙与功耗墙：大模型时代瓶颈
- 性能分析工具与 Roofline 入门（NSYS/NCU）

### 第 2 章：底层计算原语：SIMD 与 GEMM 的极致优化

- SIMD（SSE/AVX/NEON）与向量化思想
- GEMM 数学与瓶颈：tiling / cache blocking / register blocking
- 高性能库视角：cuBLAS/MKL/（黑盒与可推断策略）
- 多数据类型：FP16/BF16/INT8/FP8 与硬件支持
- \[实践\] 可选：简化版分块 GEMM（理论为主，配少量代码）

### 第 3 章：面向硬件的自动化模型设计（AutoML 与 NAS）

- NAS 核心：搜索空间/策略/评估
- HW-NAS：加入 latency/power/memory 约束
- 工具链：Optuna / Ray Tune / NNI 等
- \[实践\] 小规模 HW-NAS 流程原型

## 2. 模块二：大模型高效预训练与后训练优化

### 第 4 章：大规模预训练核心技术与挑战

- 数据工程：清洗/去重/加载流水线
- 分布式训练范式：DP/TP/PP/ZeRO/FSDP 与混合并行

- 量化：PTQ/QAT、低比特、工具链与硬件支持
- 剪枝：结构化/非结构化、稀疏格式与加速可行性
- 蒸馏：teacher-student、多种蒸馏范式
- \[综合实践\] 对一个开源模型做端到端后训练优化方案

## 6. 与本仓库“完善代码架构”的结合点（建议）

这套大纲要想真正“落地成仓库价值”，建议把工程目标显式化为三类资产：

- **可复现的 benchmark suite**：统一计时、warmup、统计、NVTX 标注、可回归
- **可扩展的算子库骨架**：稳定 API + 后端可插拔（CUDA/CANN/ROCm/…）
- **可验证的 profiling 产物**：每个关键结论都有 NCU/NSYS/SASS 证据落盘到 `docs/results/`
