# ASPL 文风：禁词与替代表（散文段）

改叙述时对照。**表单元格、代码、参考文献条目不强制替换术语。**

## 中文：开场 / 过渡

| 砍 | 可换成 |
|---|---|
| 综上所述 / 总而言之 / 由此可见 | 直接写结论句；或删 |
| 值得注意的是 / 需要指出的是 / 需要注意的是 | 删；把注意点写成表行或误区行 |
| 不难发现 / 显而易见 | 删；给证据或命令 |
| 让我们（来）看看 / 接下来我们将 | 删；下一句直接进事实 |
| 本节将详细介绍 / 下面详细展开 | 删；用小标题承载 |
| 在开始之前 / 在深入之前 | 删；边界表已说清就别铺垫 |

## 中文：时代腔 / 咨询腔

| 砍 | 可换成 |
|---|---|
| 在当今…背景下 / 随着…飞速发展 | 删；点名架构或 API |
| 在…的浪潮中 / 赋能 / 助力 / 闭环 / 抓手 | 删或改成具体动作 |
| 打造 / 构建…体系 / 全方位 | 改成「做 X / 测 Y / 回 Z 章」 |
| 落地生花 / 行之有效 / 不可或缺 | 删；写判停条件 |
| 本质上 / 深层次 / 归根结底 | 多数可删；留下物理句 |

## 中文：假对比 / 假递进

| 砍 | 可换成 |
|---|---|
| 不是 A，而是 B（连续两轮以上） | 只写 B；A 若必要放边界表 |
| 不仅…而且… / 既要…又要…（空） | 拆成两条可执行建议 |
| 一方面…另一方面…（无处方） | 决策表两行 |
| 各有优劣，需结合实际 | 写「该上 / 别上 / 回哪章」 |

## 英文残留（中文稿里也杀）

delve, tapestry, landscape (metaphor), testament, pivotal, vibrant, robust (vague), leverage (verb), unlock, unleash, game-changer, cutting-edge (empty), it's worth noting, in today's…, navigate the…, journey

## 标点与格式（散文）

- 少用长破折号（——）堆戏剧停顿；优先句号拆句。
- 少用「：」后面再跟一整段抒情；冒号留给「标签：短说明」或表头。
- 加粗预算：每小节 ≤2 处，只标数字 / API / 判停词。
- 禁止 emoji 清单、禁止「✨🔑💡」装饰。

## 保留（不要当 AI 味误杀）

- `sm_80+`、`__shfl_down_sync`、`--mode sweep`、median、sectors/request
- 「主看加速比」「禁止把 ncu 附着墙钟当结论」类硬口径句
- 文献「约 1.2×～2×（文献形状；以本机为准）」——有锚点就留
